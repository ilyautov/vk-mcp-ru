# VK для бизнеса через MCP

Ставит сервер `vk-mcp` из пакета `vk-mcp-ru`: 373 метода (чтение 159,
запись 173, необратимое 41), каталог собран из официальной схемы
`VKCOM/vk-api-schema`. В каталог включены бизнес-разделы: товары, сообщества,
реклама, диалоги, статистика, лид-формы.

## Установка

```json
{
  "mcpServers": {
    "vk": {
      "command": "uvx",
      "args": ["--from", "vk-mcp-ru", "vk-mcp"],
      "env": { "VK_TOKEN": "<сервисный ключ или токен сообщества>" }
    }
  }
}
```

## Где взять токен

`dev.vk.com` → создать приложение → сервисный ключ доступа. Для действий от
имени сообщества нужен токен сообщества с правами `market`, `messages`, `ads`,
`stats` — те, что реально нужны, лишние не запрашивай.

## Что спрашивать у сервера

- `vk_search_methods("товары сообщества")` — поиск метода словами.
- `vk_describe_method(...)` — параметры и класс доступа.
- `vk_call_method(...)` — прочитать: чтение идёт сразу, без подтверждения.
- `vk_write_method(...)` — записать, нужен `confirm_write`.
- `vk_delete_method(...)` — удалить или изменить необратимо, нужны оба
  подтверждения. Инструмент один на класс доступа: чтение не спрашивает
  разрешения, запись и удаление спрашивают всегда.

## Осторожно

`groups.ban`, `market.delete`, `wall.delete` помечены как необратимые: агент
обязан спросить. Отправка сообщений клиентам это запись, и её тоже стоит
показывать человеку до отправки, а не после.
